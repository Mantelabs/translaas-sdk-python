# Basic Python Example

Basic Python application demonstrating translation lookups, caching, and error handling.

## Setup

```bash
cd examples/basic
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Running

```bash
python main.py
```

## Features Demonstrated

- Basic translation lookups
- Caching configuration
- Error handling
- Async/await usage
